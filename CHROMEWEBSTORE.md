**Detailed Description** [REQUIRED]
📄 Offline PDF Tools – Private, Offline PDF Editor for Chrome

Offline PDF Tools is a powerful, desktop-quality Chrome extension that lets you edit, optimize, and secure PDF files entirely offline, directly inside your browser. 

With this extension, you get a full suite of 15 essential PDF utilities to merge, split, extract, rotate, delete, compress, watermark, protect, and repair PDF pages without ever uploading your files to an external server. Everything runs locally on your device in WebAssembly and JavaScript, ensuring absolute privacy and full control over your documents.

If you’re tired of online PDF converters that require cloud uploads, account registrations, or monthly subscriptions, Offline PDF Tools is the secure, private, and instant alternative.

🔒 100% Offline & Privacy-First
Your documents never leave your device.
✔ No file uploads
✔ No external servers
✔ No telemetry or tracking
✔ No data analytics
✔ No login or account required
All PDF processing happens locally in-browser in temporary memory buffers, and files are only saved to disk when you choose to download them.

🛠 What You Can Do
📑 Merge PDFs
Combine multiple PDF files into a single document.
- Drag-and-drop file upload
- Reorder files before merging
- Export instantly

✂️ Split PDFs by Page Range
Extract pages from a PDF using flexible page range syntax (e.g. 1-3, 5, 7-10).
- Validates ranges against page counts on the fly
- Exports only selected spans

📋 Extract Pages
Select individual pages from a PDF visually to compile a new document.
- High-resolution visual page thumbnails
- Interactive selection controls

🔀 Reorder Pages
Rearrange PDF pages visually.
- Drag-and-drop thumbnails
- Interactive keyboard reordering support

🗑 Delete Pages
Remove unwanted pages safely.
- Safeguard protects against deleting all pages

🔄 Rotate Pages
Rotate pages by fixed angles (90°, 180°, 270°) independently.

🔓 Unlock PDF
Decrypt and remove password security from protected PDFs locally.

🔒 Protect PDF
Encrypt PDFs with custom user and owner passwords offline. Set permissions to restrict printing, content copying, or editing.

🛠️ Repair PDF
Reconstruct cross-reference tables (xref) and trailers of damaged or broken PDFs locally.

✍️ Edit Metadata
Update document header properties (Title, Author, Subject, Keywords) offline.

📉 Compress PDF
Shrink file sizes losslessly by deflating object streams in-browser.

💧 Watermarks & Page Numbers
Draw custom text watermarks (color, size, opacity, rotation angle) and stamp dynamic page numbers (e.g. "Page X of Y" in 6 standard positions) simultaneously.

↩️ Global Undo/Redo
Travel backward or forward through page selections, rotations, and reorder adjustments with keyboard shortcuts (Ctrl/Cmd + Z and Ctrl/Cmd + Y) and UI buttons.

📋 Action Presets (Blueprints)
Save a customized sequence of page actions to local storage and apply them instantly to newly uploaded documents.

🖥 Full-Page App Experience
Offline PDF Tools opens as a full-page tab workspace, not a cramped popup. This provides:
- More workspace for visual editing
- Better performance for large files
- High-fidelity canvas previews

🌗 Clean & Modern UI
- Sleek category filter navigation
- Light and dark theme support with dimming thumbnails toggle
- Responsive desktop card grid with micro-animations

⚡ Fast & Reliable
- Built with modern web standards (pdf-lib and PDF.js)
- No waiting for slow network uploads or server queues

🔐 Minimal Permissions
Offline PDF Tools requests only one permission:

No access to browsing history, website data, or external servers.
